# IVeuromancer.github.io

Personal site for Jane Simko, PhD, hosted on GitHub Pages.

## Before publishing

1. Drop a real CV PDF into `files/` named `JaneSimko_resume.pdf` (or update the
   filename in the "Download CV" link in `index.html`).
2. Drop a profile photo into `images/` named `profile.jpg` (or update the path
   in `index.html`).
3. Double check the publication list, awards, etc. are current — this was
   generated from a resume snapshot and the `IVeuromancer/IVeuromancer`
   profile README.

## Local preview

Just open `index.html` in a browser — no build step required.

## Deploy

Push to a repo named exactly `IVeuromancer.github.io` on GitHub (see setup
steps in the parent conversation). GitHub Pages serves it automatically at
https://IVeuromancer.github.io/ once the repo exists.
